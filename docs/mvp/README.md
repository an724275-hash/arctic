# Приёмка MVP

Источник: docs/criteria/case6-latest-text.txt. requirements.json содержит каждый проверяемый пункт исходного задания; статус «требует текущей приёмки» не означает отсутствие реализации.

Уточнение команды 14 октября: SMTP-провайдера, приложения VK ID заказчика и Zoom/Webinar нет. Реальную доставку и внешние подключения нельзя заявлять выполненными. Email-вход доступен, личные ссылки защиты задаёт организатор. Предусмотренные ТЗ официальные сроки, история 2021–2023, победители, призы и материалы должны подтверждаться заказчиком; выдумывать их нельзя.

Новая интеграция: GigaChat через серверный /assistant/ask, вопрос до 1000 знаков, ответ до 500 токенов. Требуются вход и явное согласие отправить текст. Профиль и файлы не передаются. Активный тест блокирует запросы на сервере. Лимиты: 8 запросов на пользователя в час и 100 в сутки на сайт, учёт в PostgreSQL. Лимит другого проекта общего аккаунта контролирует сам провайдер. Корневой сертификат Минцифры применяется только для клиента GigaChat; проверка TLS включена.

Проверки реализации: 94 backend-теста прошли после запуска локального PostgreSQL; сборка Vite прошла. Реальный запрос с VPS подтверждён: OAuth и генерация ответа успешно выполнены с проверкой TLS. Один предыдущий запрос завершился таймаутом; ошибка обрабатывается без раскрытия секретов. Полный визуальный проход, нагрузочное испытание и закрытие всех строк ТЗ продолжаются.
